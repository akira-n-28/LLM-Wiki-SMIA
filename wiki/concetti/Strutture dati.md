# Strutture dati

Pagina di navigazione per le strutture dati trattate nel corso [[Tecniche di Programmazione]].

## Strutture trattate

- [[Tabella hash]] — dizionario con accesso $O(1)$ atteso; gestione collisioni (chaining, open addressing)
- [[Albero binario di ricerca]] — BST; operazioni $O(h)$; bilanciamento

## Strutture implicate in algoritmi

- **Heap (min-heap):** usato in [[Algoritmo di Dijkstra]], [[Interval Partitioning]], [[Algoritmo di Prim]] — $O(\log n)$ per insert e extract-min
- **Union-Find:** usato in [[Algoritmo di Kruskal]] — $O(\alpha(n))$ per union e find (quasi costante)
- **Coda/Stack:** strutture lineari di base

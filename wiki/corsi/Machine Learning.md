# Machine Learning

Corso di **Machine Learning** tenuto dal prof. **[[Rodolà, Emanuele]]** nell'A.A. 2024/2025, SMIA, Sapienza.

> Ha un'impronta più matematica/strutturale: regressioni, gradient descent, MLP, PCA. Complementare a [[Informatica per il Machine Learning]].

## Programma

1. **Introduzione** ([[Curse of dimensionality]], prior knowledge, training/test data)
2. **Ripasso algebra lineare** ([[Norma di Frobenius]], spazi vettoriali, mappe lineari)
3. **Regressioni a dipendenza lineare**
   3.1 [[Regressione lineare]]
   3.2 [[Regressione polinomiale]]
   3.3 [[Regressione logistica]]
   3.4 Sistemi sottodeterminati e [[Regolarizzazione di Tikhonov]]
4. **Discesa del gradiente** — [[Discesa del gradiente]], [[Stochastic Gradient Descent]]
5. **Multi-Layer Perceptron & Backpropagation**
   - [[Multi-Layer Perceptron]], [[Teorema di approssimazione universale]]
   - [[Grafo computazionale]], [[Backpropagation]]
6. **Principal Component Analysis**
   - [[Quoziente di Rayleigh]], autovalori e autovettori, [[Power iteration]]
   - [[Singular Value Decomposition]]
   - [[Principal Component Analysis]]
7. **Dimensionality reduction**
   - [[Spazio metrico]], [[Embedding isometrico]]
   - [[Multidimensional Scaling]]
   - [[Stochastic Neighbor Embedding]]
   - [[t-SNE]]
8. **Metodi Ensemble**
   - [[Decision Tree]] (incluso decision stump)
   - [[Random Forest]] (bagging)
   - [[AdaBoost]], [[Gradient Boosting]]
